## 📘 Phase 1: Learn the Basics of Any Language

Think of programming basics as the ingredients of a recipe. You need to know how to write code (syntax), make decisions (conditionals), repeat tasks (loops), and reuse code (functions).

### 1. Syntax

Syntax is the grammar of a programming language, like rules for writing Tamil or English sentences.

**Example in Java** (Print a message):
```java
public class Main {
    public static void main(String[] args) {
        int age = 25;
        System.out.println("My age is " + age);
    }
}
```

**Example in Python**:
```python
age = 25
print("My age is", age)
```

**Example in JavaScript**:
```javascript
let age = 25;
console.log("My age is", age);
```

**Try It**: Write code to print “I love Tamil Nadu!” in all three languages.

### 2. Loops & Conditionals

- **Conditionals** are like choosing between dosa or idli based on your mood.
- **Loops** are like grinding rice for dosa batter multiple times.

**Conditionals Example in Python**:
```python
age = 20
if age > 18:
    print("You can vote!")
else:
    print("Wait until you’re 18!")
```

**Loops Example in Java** (For Loop):
```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Number: " + i);
        }
    }
}
```

**Try It**: Write a loop to print your favorite Tamil movie names (e.g., “Baahubali”, “Enthiran”).

### 3. Functions

Functions are like recipes you can reuse. Write the code once, use it many times.

**Python Function Example** (Calculate Pongal meal cost):
```python
def meal_cost(dosa, coffee):
    return dosa * 50 + coffee * 20

print(meal_cost(2, 1))  # Output: 120 (2 dosas + 1 coffee)
```

**Java Function Example**:
```java
public class Main {
    public static int mealCost(int dosa, int coffee) {
        return dosa * 50 + coffee * 20;
    }
    public static void main(String[] args) {
        System.out.println(mealCost(2, 1)); // Output: 120
    }
}
```

**Try It**: Create a function to calculate the total score of a cricket game.

## 📗 Phase 2: Object-Oriented Programming (OOP)

OOP is like building a house: a **class** is the blueprint, and an **object** is the actual house. It makes code organized and reusable.

### Main Concepts

#### Class and Object
A class defines properties (like name) and actions (like greet). An object is a specific instance.

**Java Example** (Tamil Nadu Bus):
```java
public class Bus {
    String route;
    
    Bus(String route) {
        this.route = route;
    }

    void displayRoute() {
        System.out.println("Bus route: " + route);
    }

    public static void main(String[] args) {
        Bus bus1 = new Bus("Chennai-Madurai");
        bus1.displayRoute(); // Output: Bus route: Chennai-Madurai
    }
}
```

**Python Example**:
```python
class Bus:
    def __init__(self, route):
        self.route = route

    def display_route(self):
        print("Bus route:", self.route)

bus1 = Bus("Chennai-Madurai")
bus1.display_route()  # Output: Bus route: Chennai-Madurai
```

#### Inheritance
Inheritance lets one class (e.g., `ExpressBus`) use properties of another (e.g., `Bus`).

**Java Example**:
```java
public class Bus {
    String route;
    Bus(String route) {
        this.route = route;
    }
    void move() {
        System.out.println("Bus is moving");
    }
}

public class ExpressBus extends Bus {
    ExpressBus(String route) {
        super(route);
    }
    public static void main(String[] args) {
        ExpressBus bus = new ExpressBus("Chennai-Coimbatore");
        bus.move(); // Output: Bus is moving
    }
}
```

#### Encapsulation
Hide data (like a safe) and use methods to access it.

**Python Example**:
```python
class Student:
    def __init__(self, name):
        self._name = name  # Private
    def get_name(self):
        return self._name
    def set_name(self, name):
        self._name = name

s = Student("Priya")
print(s.get_name())  # Output: Priya
s.set_name("Anu")
print(s.get_name())  # Output: Anu
```

#### Polymorphism
Same method, different behavior—like how “run” differs for a bus and a bike.

**JavaScript Example**:
```javascript
class Vehicle {
    move() {
        return "Vehicle is moving";
    }
}

class Bus extends Vehicle {
    move() {
        return "Bus travels on roads";
    }
}

class Bike extends Vehicle {
    move() {
        return "Bike zooms fast";
    }
}

const bus = new Bus();
const bike = new Bike();
console.log(bus.move()); // Output: Bus travels on roads
console.log(bike.move()); // Output: Bike zooms fast
```

**Try It**: Create a `Shop` class for a coffee shop with items like `dosa` and `coffee`.

## 📙 Phase 3: Data Structures and Algorithms (DSA)

DSA is like organizing your kitchen (data structures) and cooking efficiently (algorithms).

### 🧱 Data Structures and Their Use Cases

1. **Array** – `[1, 2, 3]`: Store fixed-size lists (e.g., student marks)
2. **String** – `"hello"`: Store and manipulate text (e.g., names, sentences)
3. **List** – *Dynamic array*: Flexible, resizable list (e.g., to-do items)
4. **Stack** – *Last In, First Out*: Used in undo/redo features or backtracking
5. **Queue** – *First In, First Out*: Used in customer queues, task schedulers
6. **HashMap** – `{ key: value }`: Fast lookups (e.g., phonebook, config data)

**JavaScript Example** (Array and HashMap):
```javascript
// Array
let movies = ["Baahubali", "Enthiran"];
console.log(movies[0]); // Output: Baahubali

// HashMap (Object)
let student = { name: "Alagappan", age: 20 };
console.log(student.name); // Output: Alagappan
```

### 📘 Algorithms and Their Use Cases

- **Sorting**: Arrange data (e.g., Bubble Sort)
- **Searching**: Find data (e.g., Linear Search)
- **Recursion**: Solve problems like factorial
- **Two Pointers**: Find pairs in arrays
- **Sliding Window**: Process ranges efficiently
- **Backtracking**: Solve puzzles
- **Dynamic Programming**: Optimize repeated calculations



**Python Example (Linear Search)**:
```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1

movies = ["Baahubali", "Enthiran", "Kaala"]
print(linear_search(movies, "Enthiran"))  # Output: 1
```

**Java Example (Bubble Sort)**:
```java
public class Main {
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n-1; i++) {
            for (int j = 0; j < n-i-1; j++) {
                if (arr[j] > arr[j+1]) {
                    int temp = arr[j];
                    arr[j] = arr[j+1];
                    arr[j+1] = temp;
                }
            }
        }
    }

    public static void main(String[] args) {
        int[] numbers = {64, 34, 25, 12};
        bubbleSort(numbers);
        for (int num : numbers) {
            System.out.print(num + " "); // Output: 12 25 34 64
        }
    }
}
```

* **Day 11–15: Functions** – Write a function to calculate a shopping bill or area of a circle

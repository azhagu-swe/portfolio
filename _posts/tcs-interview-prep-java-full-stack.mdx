## Core Java

### 1. Difference Between HashSet and HashMap

- **HashSet**: Stores unique objects, no duplicates. It’s like a bag where each item is unique, using a hash table for fast lookups (O(1) average).  
- **HashMap**: Stores key-value pairs, where keys are unique. It’s like a dictionary mapping keys to values, also using a hash table.  
- **Key Difference**: `HashSet` holds only values; `HashMap` holds key-value pairs. `HashSet` uses `add()`, `HashMap` uses `put()`.  
- **Example**: In FarmConnect, use `HashSet` for unique product categories and `HashMap` to map user IDs to cart details.  
- **Code Sample**:
  ```java
  import java.util.HashMap;
  import java.util.HashSet;

  public class HashSetVsHashMap {
      public static void main(String[] args) {
          // HashSet: Unique categories
          HashSet<String> categories = new HashSet<>();
          categories.add("Fruits");
          categories.add("Fruits"); // Duplicate ignored
          System.out.println("Categories: " + categories); // Output: [Fruits]

          // HashMap: User ID to name
          HashMap<Long, String> userMap = new HashMap<>();
          userMap.put(1L, "Azhagu");
          userMap.put(2L, "Mani");
          System.out.println("User Map: " + userMap); // Output: {1=Azhagu, 2=Mani}
      }
  }
  ```

### 2. Threads and Multithreading

- **Thread**: A single execution path in a program. Java supports threads via the `Thread` class or `Runnable` interface.  
- **Multithreading**: Running multiple threads to handle tasks like API calls or background jobs.  
- **Key Concepts**: Use `synchronized` for thread safety, `ExecutorService` for thread pools.  
- **Example**: In FarmConnect, one thread could process user orders, another updates inventory.  
- **Code Sample**:
  ```java
  import java.util.concurrent.ExecutorService;
  import java.util.concurrent.Executors;

  public class MultiThreadExample {
      public static void main(String[] args) {
          ExecutorService executor = Executors.newFixedThreadPool(2);
          executor.submit(() -> System.out.println("Processing order: " + Thread.currentThread().getName()));
          executor.submit(() -> System.out.println("Updating inventory: " + Thread.currentThread().getName()));
          executor.shutdown();
      }
  }
  ```
- **Practical Tip**: Relate this to your Memob Plus work, where you handled background tasks.

### 3. If Two Requests (GET and POST) Come to a Controller, Which Processes First?

- **Answer**: Spring Boot’s default server (Tomcat) processes requests based on arrival time, not type (GET or POST). The thread pool assigns threads from a queue. For same-user updates (e.g., POST to update cart), use `@Transactional` for data consistency.  
- **Example**: In FarmConnect, if a user fetches (GET) and updates (POST) their cart, requests are processed in order of arrival.  
- **Code Sample**:
  ```java
  import org.springframework.transaction.annotation.Transactional;
  import org.springframework.web.bind.annotation.*;

  @RestController
  @RequestMapping("/cart")
  public class CartController {
      @GetMapping("/{userId}")
      public String getCart(@PathVariable Long userId) {
          return "Cart for user " + userId;
      }

      @PostMapping("/{userId}")
      @Transactional
      public String updateCart(@PathVariable Long userId, @RequestBody String item) {
          return "Updated cart for user " + userId + " with " + item;
      }
  }
  ```
- **Practical Tip**: Explain how `@Transactional` ensures no partial updates in FarmConnect.

### 17. Connecting Two Databases in Spring Boot

- **What**: Connect two databases (e.g., PostgreSQL for users, MySQL for products) in one app.  
- **Approach**:  
  1. Define two `DataSource` beans in a configuration class.  
  2. Create two `EntityManagerFactory` beans, each linked to one `DataSource`.  
  3. Create two `TransactionManager` beans.  
  4. Use `@Primary` to mark the default beans.  
  5. In your repository interfaces, specify which entity manager and transaction manager to use.  
- **Example**: In FarmConnect, store user profiles in PostgreSQL and product inventory in MySQL.  
- **Code Sample**:
  ```java
  package com.example.demo.config;

  import org.springframework.beans.factory.annotation.Qualifier;
  import org.springframework.boot.jdbc.DataSourceBuilder;
  import org.springframework.context.annotation.Bean;
  import org.springframework.context.annotation.Configuration;
  import org.springframework.context.annotation.Primary;
  import org.springframework.data.jpa.repository.config.EnableJpaRepositories;
  import org.springframework.orm.jpa.LocalContainerEntityManagerFactoryBean;
  import org.springframework.orm.jpa.JpaTransactionManager;
  import org.springframework.orm.jpa.vendor.HibernateJpaVendorAdapter;

  import javax.sql.DataSource;

  @Configuration
  public class DatabaseConfig {

      @Bean(name = "primaryDataSource")
      @Primary
      public DataSource primaryDataSource() {
          return DataSourceBuilder.create()
                  .url("jdbc:postgresql://localhost:5432/userdb")
                  .username("postgres")
                  .password("password")
                  .driverClassName("org.postgresql.Driver")
                  .build();
      }

      @Bean(name = "secondaryDataSource")
      public DataSource secondaryDataSource() {
          return DataSourceBuilder.create()
                  .url("jdbc:mysql://localhost:3306/productdb")
                  .username("root")
                  .password("password")
                  .driverClassName("com.mysql.cj.jdbc.Driver")
                  .build();
      }

      @Bean(name = "primaryEntityManagerFactory")
      @Primary
      public LocalContainerEntityManagerFactoryBean primaryEntityManagerFactory(
              @Qualifier("primaryDataSource") DataSource dataSource) {
          LocalContainerEntityManagerFactoryBean em = new LocalContainerEntityManagerFactoryBean();
          em.setDataSource(dataSource);
          em.setPackagesToScan("com.example.demo.user.entity");
          em.setJpaVendorAdapter(new HibernateJpaVendorAdapter());
          return em;
      }

      @Bean(name = "secondaryEntityManagerFactory")
      public LocalContainerEntityManagerFactoryBean secondaryEntityManagerFactory(
              @Qualifier("secondaryDataSource") DataSource dataSource) {
          LocalContainerEntityManagerFactoryBean em = new LocalContainerEntityManagerFactoryBean();
          em.setDataSource(dataSource);
          em.setPackagesToScan("com.example.demo.product.entity");
          em.setJpaVendorAdapter(new HibernateJpaVendorAdapter());
          return em;
      }

      @Bean(name = "primaryTransactionManager")
      @Primary
      public JpaTransactionManager primaryTransactionManager(
              @Qualifier("primaryEntityManagerFactory") LocalContainerEntityManagerFactoryBean emf) {
          return new JpaTransactionManager(emf.getObject());
      }

      @Bean(name = "secondaryTransactionManager")
      public JpaTransactionManager secondaryTransactionManager(
              @Qualifier("secondaryEntityManagerFactory") LocalContainerEntityManagerFactoryBean emf) {
          return new JpaTransactionManager(emf.getObject());
      }
  }
  ```

### 23. Reverse a String Without Using Inbuilt Functions

- **Approach**: Use a two-pointer technique. Convert the string to a char array, swap characters from start and end, and move pointers inward.  
- **Code Sample**:
  ```java
  public class StringReverse {
      public String reverseString(String str) {
          char[] charArray = str.toCharArray();
          int left = 0;
          int right = charArray.length - 1;
          while (left < right) {
              char temp = charArray[left];
              charArray[left] = charArray[right];
              charArray[right] = temp;
              left++;
              right--;
          }
          return new String(charArray);
      }
  }
  ```
- **Practical Tip**: Explain time complexity (O(n)) and space complexity (O(n)).

### 24. Second Highest Value in Array Using Stream

- **Problem**: Find the second-largest number.  
- **Code Sample**:

  ```java
  import java.util.Arrays;

  public class SecondHighest {
      public int findSecondHighest(int[] arr) {
          return Arrays.stream(arr)
                       .distinct()
                       .sorted()
                       .skip(Math.max(0, arr.length - 2))
                       .findFirst()
                       .orElseThrow(() -> new IllegalArgumentException("Array too small"));
      }
  }
  ```

### 25. Maximum Subarray Problem

- **Problem**: Find the subarray with the largest sum.  
- **Code Sample**:

  ```java
  public class MaxSubArray {
      public int maxSubArray(int[] nums) {
          int maxSum = nums[0];
          int currentSum = nums[0];
          for (int i = 1; i < nums.length; i++) {
              currentSum = Math.max(nums[i], currentSum + nums[i]);
              maxSum = Math.max(maxSum, currentSum);
          }
          return maxSum;
      }
  }
  ```

### 28. JWT Token

- **What**: JSON Web Token for secure authentication (Header, Payload, Signature).  
- **Example**: Secured FarmConnect APIs with JWT.  
- **Code Sample**:
  ```java
  import io.jsonwebtoken.Jwts;
  import io.jsonwebtoken.SignatureAlgorithm;

  public class JwtUtil {
      private String secret = "mySecretKey";

      public String generateToken(String username) {
          return Jwts.builder()
                  .setSubject(username)
                  .signWith(SignatureAlgorithm.HS512, secret)
                  .compact();
      }
  }
  ```

### 29. Unit Test vs. Mockito

### Challenge 1: Word Search (LeetCode 79)

This is a classic grid traversal problem that tests your ability to implement a backtracking algorithm.

**Problem Statement:**
Given an `m x n` grid of characters `board` and a string `word`, return `true` if `word` exists in the grid. The word can be constructed from letters of sequentially adjacent cells, where "adjacent" cells are horizontally or vertically neighboring. The same letter cell may not be used more than once.

**Example:**
`board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`, `word = "ABCCED"` → `true`

#### **My Approach & The Optimal Solution**

The intuition here is to use a Depth-First Search (DFS) approach. You start a search from every cell in the grid. If a cell's character matches the first letter of the word, you explore its neighbors to find the subsequent letters. The key is "backtracking": you must mark a cell as "visited" as you explore its path and then "un-mark" it when you return, so it can be used in a different potential path.

**Java Solution:**
```java
class Solution {
    private final int[][] DIRS = {{1,0},{-1,0},{0,1},{0,-1}};
    private char[][] board;
    private int m, n;
    private String word;

    public boolean exist(char[][] board, String word) {
        this.board = board;
        this.word = word;
        m = board.length;
        n = board[0].length;

        for (int r = 0; r < m; ++r)
            for (int c = 0; c < n; ++c)
                if (dfs(r, c, 0)) return true;

        return false;
    }

    private boolean dfs(int r, int c, int idx) {
        if (idx == word.length()) return true;
        if (r < 0 || r >= m || c < 0 || c >= n) return false;
        if (board[r][c] != word.charAt(idx)) return false;
        
        char temp = board[r][c]; // Save the character
        board[r][c] = '#';       // Mark as visited

        for (int[] d : DIRS)
            if (dfs(r + d[0], c + d[1], idx + 1)) return true;

        board[r][c] = temp;      // Backtrack
        return false;
    }
}
```
* **Time Complexity:** O(m × n × 4^L), where L is the length of the word.
* **Space Complexity:** O(L) for the recursion stack.

### Challenge 2: Validate Binary Search Tree (LeetCode 98)

This problem tests your knowledge of tree traversal and the fundamental properties of a Binary Search Tree (BST).

**Problem Statement:**
Given the `root` of a binary tree, determine if it is a valid binary search tree (BST). A valid BST is defined as follows:
* The left subtree of a node contains only nodes with keys **less than** the node's key.
* The right subtree of a node contains only nodes with keys **greater than** the node's key.
* Both the left and right subtrees must also be binary search trees.

**Example:**
`root = [5,1,4,null,null,3,6]` → `false` (Because 4 is in the right subtree of 5, but is less than 5).

#### **My Approach & The Optimal Solution**

The key property of a BST is that an **in-order traversal** visits the nodes in ascending sorted order. Therefore, the most elegant solution is to perform an in-order traversal and keep track of the previously visited node's value. If you ever encounter a node whose value is less than or equal to the previous node's value, the tree is not a valid BST.

**Java Solution:**
```java
class Solution {
    private Long prev = null; // Use Long to handle Integer.MIN_VALUE case

    public boolean isValidBST(TreeNode root) {
        return inorder(root);
    }

    private boolean inorder(TreeNode node) {
        if (node == null) return true;

        if (!inorder(node.left)) return false;

        if (prev != null && node.val <= prev) return false;
        prev = (long) node.val;

        return inorder(node.right);
    }
}
```
* **Time Complexity:** O(N), as we visit every node once.
* **Space Complexity:** O(H), where H is the height of the tree, for the recursion stack.

### Challenge 3: Validate IP Address (LeetCode 468)

This was the one I managed to solve! It's a string parsing problem that requires careful attention to detail and handling edge cases.

**Problem Statement:**
Given a string `queryIP`, return `"IPv4"` if it's a valid IPv4 address, `"IPv6"` if it's a valid IPv6 address, or `"Neither"` if it's not a valid IP of any type.

**Key IPv4 Rules:**
* `x1.x2.x3.x4` where `0 <= xi <= 255`.
* `xi` cannot have leading zeros (e.g., `01` is invalid).

**Key IPv6 Rules:**
* `x1:x2:...:x8` where each part `xi` is a hexadecimal string of 1 to 4 characters.
* Leading zeros are allowed.

#### **My Approach & The Optimal Solution**

The most robust way to solve this is to avoid complex regular expressions and instead parse the string directly. You can split the string by its delimiter (`.` for IPv4, `:` for IPv6) and then validate each part according to the rules. It's crucial to use `split` with a limit of `-1` to include empty parts, which would be invalid.

**Java Solution:**
```java
class Solution {
    public String validIPAddress(String queryIP) {
        if (queryIP.indexOf('.') >= 0 && isIPv4(queryIP)) return "IPv4";
        if (queryIP.indexOf(':') >= 0 && isIPv6(queryIP)) return "IPv6";
        return "Neither";
    }

    private boolean isIPv4(String s) {
        String[] parts = s.split("\\.", -1);
        if (parts.length != 4) return false;

        for (String p : parts) {
            if (p.isEmpty() || (p.length() > 1 && p.charAt(0) == '0')) return false;
            try {
                int val = Integer.parseInt(p);
                if (val < 0 || val > 255) return false;
            } catch (NumberFormatException e) {
                return false;
            }
        }
        return true;
    }

    private boolean isIPv6(String s) {
        String[] parts = s.split(":", -1);
        if (parts.length != 8) return false;

        for (String p : parts) {
            if (p.length() < 1 || p.length() > 4) return false;
            for (char ch : p.toCharArray()) {
                boolean isDigit = ch >= '0' && ch <= '9';
                boolean isLowerHex = ch >= 'a' && ch <= 'f';
                boolean isUpperHex = ch >= 'A' && ch <= 'F';
                if (!(isDigit || isLowerHex || isUpperHex)) return false;
            }
        }
        return true;
    }
}
```
* **Time Complexity:** O(L), where L is the length of the input string.
* **Space Complexity:** O(1).

# 🧠 Java Collections for Interviews (2025) - Beginner-Friendly

_Your guide to mastering Java Collections, including List, Set, Map, Queue, and key implementations like ArrayList, HashSet, and ConcurrentHashMap for interviews!_

## Introduction
The Java Collections Framework is a powerful set of classes and interfaces for storing and manipulating groups of objects. Understanding collections like `List`, `Set`, `Map`, and `Queue`, along with their implementations and features like synchronization, is crucial for Java interviews. This beginner-friendly guide explains these concepts with examples and answers common interview questions to help you prepare confidently.

## Key Concepts

### 1. Java Collections Framework
The **Java Collections Framework** provides a standardized architecture for handling collections of objects. It includes:
- **Interfaces**: `List`, `Set`, `Map`, `Queue`, etc.
- **Implementations**: Classes like `ArrayList`, `HashSet`, `TreeMap`, etc.
- **Utilities**: Methods in `Collections` class (e.g., `sort`, `reverse`).

**Why it matters**: Collections are used in almost every Java application for data storage and manipulation.

### 2. List
A `List` is an ordered collection that allows duplicates. Key implementations:
- **ArrayList**: Resizable array, fast for random access.
- **Vector**: Synchronized, thread-safe version of ArrayList, but slower.
- **LinkedList**: Doubly-linked list, efficient for insertions/deletions.

**Example**:
```java
List<String> list = new ArrayList<>();
list.add("Apple");
list.add("Banana");
System.out.println(list); // [Apple, Banana]
```

### 3. Set
A `Set` is a collection that does not allow duplicates. Key implementations:
- **HashSet**: Uses hashing, unordered, fast operations.
- **LinkedHashSet**: Maintains insertion order.
- **TreeSet**: Sorted, backed by a Red-Black tree.

**Example**:
```java
Set<String> set = new HashSet<>();
set.add("Apple");
set.add("Apple"); // Duplicate ignored
System.out.println(set); // [Apple]
```

### 4. Map
A `Map` stores key-value pairs, with unique keys. Key implementations:
- **HashMap**: Unordered, fast, allows one null key.
- **TreeMap**: Sorted by keys, no null keys.
- **ConcurrentHashMap**: Thread-safe, allows concurrent reads/writes.

**Example**:
```java
Map<Integer, String> map = new HashMap<>();
map.put(1, "Alice");
map.put(2, "Bob");
System.out.println(map); // {1=Alice, 2=Bob}
```

### 5. Queue
A `Queue` is designed for holding elements prior to processing, typically in FIFO order. Key implementations:
- **LinkedList**: Implements `Queue`, good for general use.
- **PriorityQueue**: Orders elements based on priority.
- **BlockingQueue**: Thread-safe, used in concurrent programming (e.g., `ArrayBlockingQueue`).

**Example**:
```java
Queue<String> queue = new LinkedList<>();
queue.offer("Task1");
queue.offer("Task2");
System.out.println(queue.poll()); // Task1
```

### 6. Synchronization
Collections like `Vector` and `Hashtable` are synchronized (thread-safe) but slower. Modern alternatives like `ConcurrentHashMap` and `CopyOnWriteArrayList` offer better performance for concurrent access.

**Example**:
```java
Map<String, Integer> syncMap = Collections.synchronizedMap(new HashMap<>());
```

### 7. ArrayList vs. Vector
- **ArrayList**: Non-synchronized, faster, preferred for single-threaded applications.
- **Vector**: Synchronized, thread-safe, but slower due to locking.

### 8. Specialized Collections
- **EnumSet**: Optimized for enum values, very fast.
- **ConcurrentHashMap**: Thread-safe map with high concurrency.
- **BlockingQueue**: Thread-safe queue for producer-consumer scenarios.

**Example (EnumSet)**:
```java
enum Day { MONDAY, TUESDAY }
Set<Day> days = EnumSet.of(Day.MONDAY);
System.out.println(days); // [MONDAY]
```

## Common Interview Questions

**Q1: What is the Java Collections Framework?**
The Java Collections Framework is a set of interfaces and classes for storing and manipulating collections of objects. It includes interfaces like `List`, `Set`, `Map`, and `Queue`, and implementations like `ArrayList`, `HashSet`, and `TreeMap`.

**Q2: What is the difference between `List`, `Set`, and `Map`?**
- **List**: Ordered, allows duplicates (e.g., `ArrayList`).
- **Set**: Unordered, no duplicates (e.g., `HashSet`).
- **Map**: Key-value pairs, unique keys (e.g., `HashMap`).

**Q3: Explain `ArrayList` vs. `Vector`.**
- **ArrayList**: Non-synchronized, faster, not thread-safe.
- **Vector**: Synchronized, thread-safe, slower due to locking.

**Q4: What is a `HashSet`?**
A `HashSet` is a `Set` implementation that uses hashing to store unique elements. It’s unordered and offers constant-time performance for add, remove, and contains operations.

**Q5: What is a `LinkedHashSet`?**
A `LinkedHashSet` is a `Set` that maintains insertion order while ensuring no duplicates, using a combination of hash table and linked list.

**Q6: What is a `TreeMap`?**
A `TreeMap` is a `Map` implementation that stores key-value pairs in sorted order (based on keys) using a Red-Black tree. It does not allow null keys.

**Q7: What is an `EnumSet`?**
An `EnumSet` is a specialized `Set` for enum values, highly efficient due to bit-vector representation. Example: `EnumSet.of(Day.MONDAY)`.

**Q8: What is a `BlockingQueue`?**
A `BlockingQueue` is a thread-safe `Queue` used in concurrent programming. It blocks operations when the queue is full (for `put`) or empty (for `take`). Example: `ArrayBlockingQueue`.

**Q9: What is a `ConcurrentHashMap`?**
A `ConcurrentHashMap` is a thread-safe `Map` that allows concurrent reads and writes with minimal locking, using segmented locking for better performance.

**Q10: How does `HashMap` work internally?**
`HashMap` uses a hash table with an array of buckets. Keys are hashed to determine their bucket, and collisions are resolved using linked lists or trees (Java 8+).

**Q11: What is the difference between `HashMap` and `Hashtable`?**
- **HashMap**: Non-synchronized, allows one null key, faster.
- **Hashtable**: Synchronized, no null keys/values, slower.

**Q12: How do you make a collection thread-safe?**
Use synchronized wrappers (`Collections.synchronizedList/Map`) or thread-safe collections like `ConcurrentHashMap` or `CopyOnWriteArrayList`.

**Q13: What is the difference between `fail-fast` and `fail-safe` iterators?**
- **Fail-fast**: Throws `ConcurrentModificationException` if the collection is modified during iteration (e.g., `ArrayList`).
- **Fail-safe**: Works on a copy of the collection, no exception (e.g., `CopyOnWriteArrayList`).

**Q14: What is the `Collections` class?**
The `Collections` class provides static utility methods for manipulating collections, like `sort`, `reverse`, `synchronizedList`, and `unmodifiableList`.

**Q15: Why doesn’t `Map` extend the `Collection` interface?**
`Map` is not a true collection as it stores key-value pairs, not single elements, and has different semantics (e.g., `put` vs. `add`).

**Q16: What is the difference between `Iterator` and `ListIterator`?**
- **Iterator**: General-purpose, works on any collection, supports forward traversal and removal.
- **ListIterator**: Specific to `List`, supports forward/backward traversal, modification, and index access.

**Q17: What is a `PriorityQueue`?**
A `PriorityQueue` is a `Queue` that orders elements based on natural ordering or a custom comparator, used for priority-based processing.

**Q18: How do you sort a `List` in Java?**
Use `Collections.sort(list)` for natural ordering or `Collections.sort(list, comparator)` for custom ordering.

**Q19: What is the difference between `HashSet` and `TreeSet`?**
- **HashSet**: Unordered, faster, uses hashing.
- **TreeSet**: Sorted, slower, uses a Red-Black tree.

**Q20: What is the purpose of the `equals()` and `hashCode()` methods in collections?**
- `equals()`: Determines if two objects are logically equal (used in `HashSet`, `HashMap`).
- `hashCode()`: Generates a hash for mapping objects to buckets. Must be consistent with `equals()`.

**Q21: What happens if `hashCode()` is not overridden in a class used as a key in `HashMap`?**
The default `hashCode()` (based on memory address) is used, which may lead to poor performance or unexpected behavior if `equals()` is overridden inconsistently.

**Q22: What is a `WeakHashMap`?**
A `WeakHashMap` is a `Map` where keys are weakly referenced, allowing garbage collection if no other references exist.

**Q23: What is the `CopyOnWriteArrayList`?**
A thread-safe `List` that creates a new copy of the underlying array on each modification, ideal for read-heavy concurrent scenarios.

**Q24: What is the difference between `ArrayList` and `LinkedList`?**
- **ArrayList**: Backed by an array, fast for random access, slow for insertions/deletions.
- **LinkedList**: Backed by a linked list, fast for insertions/deletions, slow for random access.

**Q25: How does `ConcurrentHashMap` achieve thread safety?**
`ConcurrentHashMap` uses segmented locking (dividing the map into segments), allowing concurrent reads and writes with minimal contention.

**Q26: What is the `NavigableMap` interface?**
`NavigableMap` extends `SortedMap` with navigation methods like `ceilingKey`, `floorKey`, and `subMap`. `TreeMap` implements it.

## Code Example
Here’s a program demonstrating key collection concepts:
```java
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

public class CollectionsDemo {
    public static void main(String[] args) {
        // List: ArrayList
        List<String> fruits = new ArrayList<>();
        fruits.add("Apple");
        fruits.add("Banana");
        System.out.println("List: " + fruits);

        // Set: LinkedHashSet
        Set<String> colors = new LinkedHashSet<>();
        colors.add("Red");
        colors.add("Red"); // Duplicate ignored
        System.out.println("Set: " + colors);

        // Map: ConcurrentHashMap
        Map<Integer, String> students = new ConcurrentHashMap<>();
        students.put(1, "Alice");
        students.put(2, "Bob");
        System.out.println("Map: " + students);

        // Queue: PriorityQueue
        Queue<Integer> tasks = new PriorityQueue<>();
        tasks.offer(30);
        tasks.offer(10);
        System.out.println("Queue poll: " + tasks.poll()); // 10 (smallest)

        // EnumSet
        enum Status { ACTIVE, INACTIVE }
        Set<Status> statuses = EnumSet.of(Status.ACTIVE);
        System.out.println("EnumSet: " + statuses);
    }
}
```

**Output**:
```
List: [Apple, Banana]
Set: [Red]
Map: {1=Alice, 2=Bob}
Queue poll: 10
EnumSet: [ACTIVE]
```

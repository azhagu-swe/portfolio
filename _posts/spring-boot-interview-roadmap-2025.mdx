## 📘 1. Spring Core (The Foundation of Spring) 🌱

Spring Core is like the base masala for a Tamil dish—it’s the foundation of every Spring Boot app. In 2025, Spring Framework 6 uses modern practices to make coding easier.

### Key Updates for 2025
- **Jakarta EE**: Uses `jakarta.persistence` instead of `javax.*` for modern compatibility.
- **Constructor-Based DI**: Preferred over field injection for better testability.
- **Java-Based Config**: Uses `@Configuration` and `@Bean` instead of XML files.

### Must-Know Concepts
- 🫙 **Bean Scopes**: 
  - `singleton`: One instance shared across the app, like a shared recipe book.
  - `prototype`: New instance each time, like making fresh dosa batter for each order.
- 🔄 **Lifecycle Hooks**: 
  - `@PostConstruct`: Runs after a bean is created, like setting up a kitchen.
  - `@PreDestroy`: Runs before a bean is destroyed, like cleaning up after cooking.
- ⚙️ **Configuration**: 
  - `@Value`: Injects single properties, like the price of a dosa.
  - `@ConfigurationProperties`: Groups related settings, like a menu’s details.

**Example (Constructor-Based DI)**:
```java
import org.springframework.stereotype.Service;

@Service
public class MealService {
    private final IngredientRepo repo;

    // Constructor-based DI
    public MealService(IngredientRepo repo) {
        this.repo = repo;
    }

    public String prepareMeal() {
        return repo.getIngredients() + " cooked into a tasty Pongal!";
    }
}
```

## 🚀 2. Spring Boot Basics (Spring Boot 3.x)

Spring Boot 3.x is like a ready-made kitchen kit—it sets everything up for you! It requires **Java 17+** and supports modern features like **GraalVM native images**.

### Key Features
- **Starters**: Pre-configured dependencies, like `spring-boot-starter-web` for web apps.
- **Auto-Configuration**: `@SpringBootApplication` sets up defaults via `spring.factories`, like an automatic spice mixer.
- **Profiles**: Use `application-dev.yaml` for environment-specific settings, like a menu for breakfast vs. dinner.

**Example (Profile-Based Config)**:
```yaml
# application.yaml
spring:
  profiles:
    active: dev
---
spring:
  config:
    activate:
      on-profile: dev
app:
  name: Tamil Restaurant App
```

**Java Code**:
```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

**Try It**: Create a Spring Boot app with two profiles (`dev` and `prod`) and print a welcome message.

## 🌐 3. Spring MVC (Building REST APIs)

Spring MVC is like serving dishes to customers via a menu (API endpoints). In 2025, REST APIs focus on clean design and modern practices.

### Key Practices
- **Annotations**: Use `@RestController`, `@GetMapping`, `@PostMapping` for JSON APIs.
- **Input Handling**: Manage inputs with `@RequestBody`, `@PathVariable`, `@RequestParam`.
- **API Versioning**: Use strategies like `/api/v1/menu` to support future updates.

**Example (REST API)**:
```java
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import jakarta.validation.Valid;

@RestController
@RequestMapping("/api/v1/menu")
public class MenuController {
    @GetMapping("/{id}")
    public ResponseEntity<String> getDish(@PathVariable Long id) {
        return ResponseEntity.ok("Dosa #" + id);
    }

    @PostMapping
    public ResponseEntity<String> addDish(@Valid @RequestBody Dish dish) {
        return ResponseEntity.status(201).body("Added: " + dish.getName());
    }
}
```

**Try It**: Build a REST API to list Tamil dishes (e.g., Dosa, Idli) with GET and POST endpoints.

## 🗃️ 4. Spring Data JPA (Managing Data)

Spring Data JPA is like organizing ingredients in a kitchen database. It uses **Jakarta EE** (`jakarta.persistence`) in 2025.

### Key Concepts
- 🗂️ **Entities**: 
  - `@Entity`, `@Id`, `@GeneratedValue` map Java objects to database tables, like storing recipe details.
- 📚 **Repositories**: 
  - `JpaRepository`: Provides CRUD operations, like adding or fetching dishes.
  - `PagingAndSortingRepository`: Adds pagination and sorting, like listing dishes by price.
- 🔎 **Queries**: 
  - `@Query`: Write custom SQL/JPQL queries, like finding dishes by name.
  - Supports joins and lazy/eager loading for efficient data retrieval.

**Example (JPA Entity and Repository)**:
```java
import jakarta.persistence.Entity;
import jakarta.persistence.Id;
import jakarta.persistence.GeneratedValue;

@Entity
public class Dish {
    @Id
    @GeneratedValue
    private Long id;
    private String name;

    // Getters and setters
}

import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;

public interface DishRepository extends JpaRepository<Dish, Long> {
    @Query("SELECT d FROM Dish d WHERE d.name LIKE ?1")
    List<Dish> findByNameLike(String name);
}
```

**Try It**: Create an `@Entity` for a Tamil festival and a repository to find festivals by name.

## 🛠️ 5. REST API + Exception Handling

Exception handling in Spring Boot is like ensuring a customer gets a clear apology if their order goes wrong. Use modern practices for clean error responses.

### Best Practices
- **Global Handling**: Use `@RestControllerAdvice` for centralized exception handling.
- **Standard Responses**: Return HTTP status codes (e.g., 400 for bad input, 404 for not found).
- **Validation**: Use `@Valid` and `BindingResult` to check inputs.

**Example (Exception Handling)**:
```java
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import jakarta.validation.ConstraintViolationException;

@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(ConstraintViolationException.class)
    public ResponseEntity<String> handleValidationError(ConstraintViolationException ex) {
        return ResponseEntity.status(400).body("Invalid input: " + ex.getMessage());
    }
}
```

**Try It**: Add a custom exception handler for a missing dish in your REST API.

## 🔐 6. Spring Security (Securing Your App)

Spring Security 6.x is like locking the kitchen to authorized chefs only. It’s updated for 2025 with modern configurations.

### Key Updates
- **Deprecated**: `WebSecurityConfigurerAdapter` is no longer used.
- **New Config**: Use `SecurityFilterChain` for security settings.
- **JWT Support**: Enables stateless authentication for APIs.

**Example (Security Config)**:
```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
public class SecurityConfig {
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/public/**").permitAll()
                .anyRequest().authenticated()
            )
            .csrf().disable();
        return http.build();
    }
}
```

**Try It**: Secure your REST API to allow only authenticated users to add dishes.

## ⚡ 7. Caching (Speeding Up Your App)

Caching is like keeping ready-made dosa batter to serve faster. Spring Boot 3.x supports **Redis** and **Caffeine** for efficient caching.

### Key Annotations
- **@Cacheable**: Stores results to avoid repeated calls, like saving a dish’s details.
- **@CachePut**: Updates the cache with new data.
- **@CacheEvict**: Clears cache entries, like removing outdated menu items.

**Example (Caching)**:
```java
import org.springframework.cache.annotation.Cacheable;
import org.springframework.stereotype.Service;

@Service
public class MenuService {
    @Cacheable("dishes")
    public String getDish(Long id) {
        // Simulate slow database call
        return "Dosa #" + id;
    }
}
```

**Try It**: Add caching to your dish retrieval API using `@Cacheable`.

## 🧪 8. Testing (Ensuring Quality)

Testing is like tasting a dish before serving. Use modern tools like **JUnit 5**, **Mockito**, and **Testcontainers** to ensure quality.

### Key Annotations
- 🧪 **@SpringBootTest**: Loads the full app context for integration tests.
- 🌐 **@WebMvcTest**: Tests controllers in isolation, like checking a menu endpoint.
- 🗃️ **@DataJpaTest**: Tests repository layers with an in-memory database.

**Example (Controller Test)**:
```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.test.web.servlet.MockMvc;

@WebMvcTest(MenuController.class)
public class MenuControllerTest {
    @Autowired
    private MockMvc mockMvc;

    @Test
    public void testGetDish() throws Exception {
        mockMvc.perform(get("/api/v1/menu/1"))
               .andExpect(status().isOk())
               .andExpect(content().string("Dosa #1"));
    }
}
```

**Try It**: Write a test for your dish API using `@WebMvcTest`.

## 🧱 9. Microservices & DevOps Basics

Microservices are like running multiple food stalls at a festival—each handles one task. Spring Boot 3.x supports modern microservice patterns.

### Key Tools
- 🕵️ **Eureka**: Registers services for discovery, like listing all festival stalls.
- 🌐 **Spring Cloud Gateway**: Routes requests to services, like directing customers to the right stall.
- 📡 **WebClient**: Calls APIs between services, replacing RestTemplate.
- 📊 **Actuator**: Provides health checks and metrics, like monitoring a stall’s status.

**Example (Microservice Setup)**:
```java
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
@EnableDiscoveryClient
public class MenuServiceApplication {
    public static void main(String[] args) {
        SpringApplication.run(MenuServiceApplication.class, args);
    }
}
```

**Try It**: Create a simple microservice to list Tamil dishes using Spring Cloud Gateway.

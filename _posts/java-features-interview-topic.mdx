# 🧠 Java 8 and 17 Features for Interviews (2025) - Beginner-Friendly

_Your guide to mastering Java 8 features like Lambdas, Streams, Optional, and Date API, plus key Java 17 enhancements, for interviews!_

## Introduction

Java 8 introduced transformative features like Lambdas, Streams, Optional, and the Date/Time API, revolutionizing how developers write code. Java 17, a Long-Term Support (LTS) release, added modern enhancements like sealed classes, records, and pattern matching. Understanding these features is essential for Java interviews, as they demonstrate your ability to write concise, functional-style code. This beginner-friendly guide explains these concepts with examples and includes suggested interview questions to help you prepare confidently.

## Key Concepts: Java 8 Features

### 1. Lambda Expressions

Lambda expressions introduce functional programming in Java, allowing you to write concise code for functional interfaces (interfaces with one abstract method). They use the `->` syntax.

**Example**:

```java
// Traditional way
Comparator<String> comparator = new Comparator<String>() {
    @Override
    public int compare(String s1, String s2) {
        return s1.compareTo(s2);
    }
};

// Lambda expression
Comparator<String> lambdaComparator = (s1, s2) -> s1.compareTo(s2);
```

**Why it matters**: Lambdas reduce boilerplate and make code more readable, especially with collections and event handling.

### 2. Streams API

The Streams API enables functional-style processing of collections, allowing operations like filtering, mapping, and reducing in a declarative way.

**Example**:

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> squares = numbers.stream()
    .filter(n -> n % 2 == 0) // Filter even numbers
    .map(n -> n * n) // Square them
    .collect(Collectors.toList());
System.out.println(squares); // [4, 16]
```

**Why it matters**: Streams simplify complex data processing and support parallel execution for performance.

### 3. Optional

`Optional` is a container that may or may not hold a value, reducing `NullPointerException` risks by encouraging explicit null handling.

**Example**:

```java
Optional<String> name = Optional.ofNullable("Alice");
System.out.println(name.orElse("Unknown")); // Alice
System.out.println(Optional.empty().orElse("Unknown")); // Unknown
```

**Why it matters**: `Optional` promotes safer, more readable code by avoiding null checks.

### 4. Date and Time API

The Java 8 Date/Time API (`java.time`) replaces the outdated `java.util.Date` and `Calendar`, providing a robust, immutable API for handling dates and times.

**Example**:

```java
LocalDate today = LocalDate.now();
LocalDate nextWeek = today.plusDays(7);
System.out.println("Today: " + today); // e.g., 2025-07-16
System.out.println("Next week: " + nextWeek); // e.g., 2025-07-23
```

**Why it matters**: The new API is thread-safe, intuitive, and supports modern date/time requirements.

## Key Concepts: Java 17 Features

Java 17, an LTS release, introduced features that enhance code readability and maintainability. Key additions include:

### 1. Records

Records are immutable data classes that reduce boilerplate for data-carrying classes, automatically providing constructors, getters, `equals()`, `hashCode()`, and `toString()`.

**Example**:

```java
record Person(String name, int age) {}
Person p = new Person("Bob", 30);
System.out.println(p); // Person[name=Bob, age=30]
```

### 2. Sealed Classes

Sealed classes restrict which classes can extend or implement them, improving control over inheritance hierarchies.

**Example**:

```java
sealed interface Shape permits Circle, Rectangle {}
final class Circle implements Shape {}
final class Rectangle implements Shape {}
```

### 3. Pattern Matching for Switch (Preview in Java 17)

Pattern matching simplifies `switch` statements by combining type testing and casting, making code more concise.

**Example**:

```java
Object obj = "Hello";
switch (obj) {
    case String s -> System.out.println("String: " + s);
    case Integer i -> System.out.println("Integer: " + i);
    default -> System.out.println("Unknown");
} // String: Hello
```

## Suggested Interview Questions

**Q1: What are Lambda expressions, and how do they work in Java 8?**
Lambda expressions are anonymous functions for functional interfaces, using `->` to define parameters and body. They simplify code for tasks like event handling or collection processing.

**Q2: How does the Streams API improve collection processing?**
Streams provide a functional approach to process collections with operations like `filter`, `map`, and `reduce`, supporting concise code and parallel execution for performance.

**Q3: What is the purpose of `Optional` in Java 8?**
`Optional` prevents `NullPointerException` by wrapping potentially null values, encouraging explicit handling with methods like `orElse` and `ifPresent`.

**Q4: How does the Java 8 Date/Time API differ from the old `java.util.Date`?**
The Java 8 Date/Time API (`java.time`) is immutable, thread-safe, and more intuitive than `java.util.Date`, which is mutable and error-prone.

**Q5: What is a record in Java 17, and when would you use it?**
A record is an immutable class for data storage, reducing boilerplate. Use it for data transfer objects (DTOs) or simple data carriers.

**Q6: What are sealed classes in Java 17, and why are they useful?**
Sealed classes restrict inheritance to specified subclasses, improving design clarity and preventing unintended extensions.

**Q7: How does pattern matching for `switch` in Java 17 simplify code?**
Pattern matching combines type checking and casting in `switch` statements, reducing boilerplate and improving readability.

**Q8: Can you use Lambdas with Streams to process data? Provide an example.**
Yes, Lambdas are often used with Streams. Example:

```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.stream().filter(name -> name.startsWith("A")).forEach(System.out::println); // Alice
```

**Q9: How do you handle nulls with `Optional` in a real-world scenario?**
Use `Optional` to safely process potentially null values, e.g., retrieving a user’s name or a default value:

```java
Optional<String> userName = Optional.ofNullable(getUserName());
String name = userName.orElse("Guest");
```

**Q10: What are the benefits of the Java 17 record over a traditional class?**
Records reduce boilerplate by auto-generating constructors, getters, `equals()`, `hashCode()`, and `toString()`, ensuring immutability and simplicity.

## Code Example

Here’s a program demonstrating Java 8 and 17 features:

```java
import java.time.LocalDate;
import java.util.*;
import java.util.stream.Collectors;

public class Java8And17Demo {
    public static void main(String[] args) {
        // Java 8: Lambda and Streams
        List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
        List<Integer> evens = numbers.stream()
            .filter(n -> n % 2 == 0)
            .collect(Collectors.toList());
        System.out.println("Evens: " + evens); // [2, 4]

        // Java 8: Optional
        Optional<String> name = Optional.ofNullable(null);
        System.out.println("Name: " + name.orElse("Unknown")); // Unknown

        // Java 8: Date API
        LocalDate today = LocalDate.now();
        System.out.println("Today: " + today);

        // Java 17: Record
        record Person(String name, int age) {}
        Person person = new Person("Alice", 25);
        System.out.println("Person: " + person);

        // Java 17: Pattern Matching Switch (Preview)
        Object obj = "Hello";
        switch (obj) {
            case String s -> System.out.println("String: " + s);
            case Integer i -> System.out.println("Integer: " + i);
            default -> System.out.println("Unknown");
        }
    }
}
```

**Output** (assuming run on 2025-07-16):

```
Evens: [2, 4]
Name: Unknown
Today: 2025-07-16
Person: Person[name=Alice, age=25]
String: Hello
```

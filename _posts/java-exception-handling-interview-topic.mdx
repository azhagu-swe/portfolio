# 🧠 Java Exception Handling for Interviews (2025) - Beginner-Friendly

_Your guide to mastering Java exception handling, including try, catch, finally, throw, throws, try-with-resources, and exception propagation for interviews!_

## Introduction
Exception handling in Java allows you to manage errors gracefully, ensuring your program remains robust. Understanding constructs like `try`, `catch`, `finally`, `throw`, `throws`, `try-with-resources`, and exception propagation is critical for Java interviews. This beginner-friendly guide explains these concepts with clear examples and answers common interview questions to help you prepare confidently.

## Key Concepts

### 1. Try and Catch
The `try` block contains code that might throw an exception. The `catch` block handles specific exceptions if they occur.

**Example**:
```java
try {
    int result = 10 / 0; // Throws ArithmeticException
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero: " + e.getMessage());
}
```

**Why it matters**: `try-catch` prevents program crashes by handling errors.

### 2. Finally
The `finally` block executes regardless of whether an exception occurs, often used for cleanup (e.g., closing resources).

**Example**:
```java
try {
    int[] arr = {1, 2};
    System.out.println(arr[2]); // Throws ArrayIndexOutOfBoundsException
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Array error: " + e.getMessage());
} finally {
    System.out.println("Cleanup in finally");
}
```

### 3. Throw
The `throw` keyword explicitly throws an exception.

**Example**:
```java
int age = -5;
if (age < 0) {
    throw new IllegalArgumentException("Age cannot be negative");
}
```

### 4. Throws
The `throws` keyword in a method signature declares that the method might throw checked exceptions, requiring the caller to handle them.

**Example**:
```java
public void readFile() throws IOException {
    throw new IOException("File not found");
}
```

### 5. Try-With-Resources
Introduced in Java 7, `try-with-resources` automatically closes resources (e.g., files, sockets) that implement `AutoCloseable`.

**Example**:
```java
try (FileReader fr = new FileReader("file.txt")) {
    // Use file reader
} catch (IOException e) {
    System.out.println("IO error: " + e.getMessage());
} // FileReader automatically closed
```

### 6. Exception Propagation
When an exception is thrown in a method and not caught, it propagates up the call stack until handled or the program terminates.

**Example**:
```java
void method1() throws IOException {
    throw new IOException("Error in method1");
}
void method2() throws IOException {
    method1(); // Propagates exception
}
```

### 7. Types of Exceptions
- **Checked Exceptions**: Must be declared or handled (e.g., `IOException`).
- **Unchecked Exceptions**: Subclasses of `RuntimeException`, don’t require handling (e.g., `NullPointerException`).

## Common Interview Questions

**Q1: What is exception handling in Java?**
Exception handling manages errors using `try`, `catch`, `finally`, `throw`, and `throws`, ensuring programs handle unexpected scenarios gracefully.

**Q2: What is the difference between `throw` and `throws`?**
- **throw**: Explicitly throws an exception (e.g., `throw new IOException()`).
- **throws**: Declares exceptions a method might throw (e.g., `void method() throws IOException`).

**Q3: What is the purpose of the `finally` block?**
The `finally` block executes regardless of whether an exception occurs, typically for cleanup tasks like closing resources.

**Q4: What is `try-with-resources`, and how does it work?**
`try-with-resources` automatically closes resources implementing `AutoCloseable` after the `try` block, reducing boilerplate code.

**Q5: What are checked and unchecked exceptions?**
- **Checked**: Must be handled or declared (e.g., `IOException`).
- **Unchecked**: Subclasses of `RuntimeException`, optional to handle (e.g., `ArithmeticException`).

**Q6: Can we have multiple catch blocks?**
Yes, multiple `catch` blocks can handle different exception types. They are evaluated in order, and the first matching block executes.

**Example**:
```java
try {
    int[] arr = null;
    System.out.println(arr[0]);
} catch (NullPointerException e) {
    System.out.println("Null error");
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Array error");
}
```

**Q7: What happens if an exception is not caught?**
It propagates up the call stack. If unhandled, the program terminates with a stack trace.

**Q8: Can we have a `try` block without a `catch` block?**
Yes, a `try` block can be used with `finally` or `try-with-resources` without a `catch`.

**Example**:
```java
try {
    System.out.println("Try block");
} finally {
    System.out.println("Finally block");
}
```

**Q9: What is exception propagation?**
When an exception is thrown and not caught in a method, it propagates to the calling method until handled or the program crashes.

**Q10: Can we throw an exception from a `catch` block?**
Yes, a `catch` block can throw a new exception or rethrow the caught exception.

**Example**:
```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    throw new RuntimeException("Math error", e);
}
```

**Q11: What is the hierarchy of exceptions in Java?**
All exceptions inherit from `Throwable`, which has two subclasses:
- `Error`: Serious issues (e.g., `OutOfMemoryError`).
- `Exception`: Recoverable issues, including `RuntimeException` (unchecked) and others (checked).

**Q12: Can a `finally` block be skipped?**
A `finally` block is skipped only if the JVM exits (e.g., `System.exit()`) or a fatal error occurs.

**Q13: What is the difference between `Error` and `Exception`?**
- **Error**: Indicates serious problems (e.g., `StackOverflowError`), usually not recoverable.
- **Exception**: Indicates recoverable issues (e.g., `IOException`, `NullPointerException`).

## Code Example
Here’s a program demonstrating exception handling concepts:
```java
import java.io.*;

public class ExceptionHandlingDemo {
    public static void main(String[] args) {
        // Try-catch-finally
        try {
            int[] arr = {1, 2};
            System.out.println(arr[2]); // Throws ArrayIndexOutOfBoundsException
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Array error: " + e.getMessage());
        } finally {
            System.out.println("Cleanup in finally");
        }

        // Try-with-resources
        try (FileReader fr = new FileReader("nonexistent.txt")) {
            System.out.println("Reading file");
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }

        // Throw and throws
        try {
            validateAge(-5);
        } catch (IllegalArgumentException e) {
            System.out.println("Invalid age: " + e.getMessage());
        }
    }

    static void validateAge(int age) throws IllegalArgumentException {
        if (age < 0) {
            throw new IllegalArgumentException("Age cannot be negative");
        }
    }
}
```

**Output**:
```
Array error: 2
Cleanup in finally
File error: nonexistent.txt (No such file or directory)
Invalid age: Age cannot be negative
```

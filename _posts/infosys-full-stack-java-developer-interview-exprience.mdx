## My Infosys Interview Experience

I appeared for the **Infosys Java Full Stack Developer** role, and the process had **4 rounds**: two technical, one managerial, and one HR. Here’s my journey.

---

## Round 1: Technical Interview (Core)

The first round focused on my **backend and frontend fundamentals**.

**Java:**

* Difference between Abstract Class vs Interface
* JVM architecture explanation
* HashMap vs ConcurrentHashMap
* Checked vs Unchecked exceptions
* Multithreading and synchronization

**Spring Boot & Microservices:**

* Spring MVC vs Spring Boot
* Dependency Injection
* REST API best practices
* Communication between microservices (Feign, REST, Kafka)
* Eureka service discovery
* Fault tolerance (circuit breakers, retries)

**SQL:**

* Second highest salary query
* JOIN types (INNER, LEFT, RIGHT)
* Normalization vs Denormalization
* Indexes (clustered vs non-clustered)
* Optimizing queries

**JavaScript & React Hooks:**

* var, let, const differences
* Event loop working
* Closures
* Promises vs async/await
* React hooks: useState, useEffect, useRef
* Virtual DOM and reconciliation

---

## Round 2: Technical + DSA

This round had **coding questions** in addition to technical discussions.

**Problem 1: Merge two lists in zig-zag order**

```js
a = [1,2,3,4,5]
b = [6,7,8,9,10]
output = [1,6,2,7,3,8,4,9,5,10]
```

**Problem 2: Extract names from JSON employee array**

```json
[
  { "id": 1, "name": "John", "role": "Dev" },
  { "id": 2, "name": "Alice", "role": "Tester" },
  { "id": 3, "name": "Bob", "role": "Manager" }
]
```

**Output:** `["John", "Alice", "Bob"]`

Other DSA discussions included:

* First non-repeating character in a string
* Palindrome check

---

## Round 3: Managerial

This round tested **real-world problem solving and ownership**.

* Explained a challenging project and how I solved critical issues
* How I handle production incidents and pressure
* Ensuring code quality and delivery under deadlines
* Prioritizing tasks with multiple stakeholders
* How I resolve conflicts in the team

---

## Round 4: HR Discussion

The HR round was straightforward:

* Why Infosys?
* My strengths and weaknesses
* Career aspirations
* Salary expectations and notice period
* Willingness to relocate and work-life balance

---

## Final Thoughts

The interview experience at Infosys was **balanced and structured**, testing both **technical expertise** and **soft skills**.
✅ Strong fundamentals in **Java, Spring Boot, SQL** are must-haves
✅ Practice **DSA coding** for round 2
✅ Prepare for **managerial questions** with real project examples
✅ HR round focuses on **culture fit and aspirations**

Overall, it was a **great learning experience** that strengthened my confidence in full-stack development and interview preparation.

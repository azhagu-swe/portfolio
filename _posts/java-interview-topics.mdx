# 🧠 Java Interview Prep Guide (2025) - Beginner-Friendly

_Your easy guide to mastering Java for interviews—covers basics, OOP, collections, and more!_

## Introduction

This guide is perfect for beginners preparing for Java interviews. Each topic is explained simply with examples to help you learn and remember. Let’s get started!

## [1. Java Basics](https://azhagu-swe.github.io/portfolio/blog/java-basics-interview)

- **Data Types**: Numbers (`int`, `double`), text (`String`), true/false (`boolean`).
- **Variables**: Containers for data, e.g., `int age = 25;`.
- **Type Casting**: Convert types, e.g., `int num = (int) 3.14;`.
- **var Keyword** (Java 10+): Java guesses the type, e.g., `var name = "Alice";`.

## [ 2. Control Flow](https://azhagu-swe.github.io/portfolio/blog/java-control-flow-interview)

- **`if` Statements**: Run code if true, e.g., `if (age > 18) { ... }`.
- **`switch` Statements**: Choose from options, like a menu.
- **Loops**: Repeat code with `for`, `while`, or `do-while`.
- **`break` and `continue`**: Stop a loop or skip to the next step.

## [3. OOP Principles ](https://azhagu-swe.github.io/portfolio/blog/java-oops-principles)

- **Encapsulation**: Hide data using `private` fields and `public` methods.
- **Inheritance**: A class inherits from another using `extends`.
- **Polymorphism**: Same method, different behavior (e.g., `dog.bark()` vs. `cat.bark()`).
- **Abstraction**: Hide details with `abstract` classes or interfaces.
- **Overriding vs. Overloading**: Overriding changes a method; overloading uses the same name with different parameters.

## [4. Java Collections](https://azhagu-swe.github.io/portfolio/blog/java-collection-interview-topic)

- **List**: Ordered items, e.g., `ArrayList` for a shopping list.
- **Set**: Unique items, e.g., `HashSet` for unique IDs.
- **Map**: Key-value pairs, e.g., `HashMap` for names and phone numbers.
- **Queue**: First-in, first-out, like a store line.

## [5. Exception Handling](https://azhagu-swe.github.io/portfolio/blog/java-exception-handling-interview-topic)

- **`try`, `catch`**: Catch errors, e.g., `try { ... } catch (Exception e) { ... }`.
- **`finally`**: Always runs, e.g., to close a file.
- **`throw`, `throws`**: Create or declare errors.
- **Try-with-Resources**: Auto-close resources, e.g., `try (FileReader fr = new FileReader("file.txt")) { ... }`.

## [6. Strings](https://azhagu-swe.github.io/portfolio/blog/java-string-interview-topic)

- **`String`**: Text like `"Hello"`. Immutable (can’t change).
- **`StringBuilder`**: Changeable text for efficiency.
- **Intern Pool**: Reuses common strings to save memory.

## [7. Java 8 and 17 Features](https://azhagu-swe.github.io/portfolio/blog/java-features-interview-topic)

- **Lambdas**: Short functions, e.g., `x -> x * 2`.
- **Streams**: Process lists easily, e.g., filter numbers.
- **`Optional`**: Avoid null errors, e.g., `Optional.of("value")`.
- **Date API**: Handle dates, e.g., `LocalDate.now()`.

## [8. Multithreading](https://azhagu-swe.github.io/portfolio/blog/java-multithreading-interview-topic)

- **`Thread`, `Runnable`**: Run tasks at the same time.
- **`ExecutorService`**: Manage multiple threads easily.
- **Synchronization**: Prevent conflicts when threads share data.
- **Deadlock**: When threads get stuck waiting for each other.

## [9. JVM & Garbage Collection](https://azhagu-swe.github.io/portfolio/blog/jvm-and-garbage-collection-interview-topics)

- **Heap/Stack**: Heap stores objects; stack stores method calls.
- **Garbage Collection**: Cleans unused objects (e.g., G1, CMS collectors).
- **`finalize()`**: Rarely used, runs before object cleanup.
- **Memory Leaks**: When unused objects aren’t cleaned.

## [10. Java I/O & NIO](https://azhagu-swe.github.io/portfolio/blog/java-o-and-nio-interview-topic)

- **Streams**: Read/write data like files.
- **Readers/Writers**: Handle text data.
- **NIO Channels**: Faster I/O for large data.

## [11. Access Modifiers](https://azhagu-swe.github.io/portfolio/blog/java-access-modifiers-interview-topic)

- **`public`**: Anyone can access.
- **`private`**: Only the class can access.
- **`protected`**: Class and subclasses can access.
- **Default**: Package-level access if no modifier.

## [12. Design Patterns](https://azhagu-swe.github.io/portfolio/blog/java-design-pattern-interview-topic)

- **Singleton**: One instance of a class, e.g., a single database connection.
- **Factory**: Create objects without specifying exact class.
- **Builder**: Build complex objects step-by-step.
- **Strategy**: Swap algorithms, e.g., different sorting methods.

## [13. SOLID Principles](https://azhagu-swe.github.io/portfolio/blog/java-solid-principles-interview-topic)

- **SRP**: One class, one job.
- **OCP**: Open for extension, closed for modification.
- **LSP**: Subclasses should work like their parent.
- **ISP**: Don’t force classes to use unneeded methods.
- **DIP**: Depend on abstractions, not concrete classes.

## [14. Advanced Java](https://azhagu-swe.github.io/portfolio/blog/java-advanced-interview-topic)

- **Reflection**: Inspect or modify code at runtime.
- **Annotations**: Add metadata, e.g., `@Override`.
- **Enums**: Define fixed values, e.g., `enum Day { MON, TUE }`.
- **Records**: Simple data classes (Java 14+).
- **Serialization**: Save objects to files or send over networks.
